Performans Metrikleri Açıklamaları
Accuracy (Doğruluk)

Toplam doğru tahminlerin toplam tahminlere oranı.

Accuracy = (TP + TN) / (TP + TN + FP + FN)
Precision (Kesinlik)

Pozitif olarak tahmin edilenler arasında gerçekten pozitif olanların oranı.

Precision = TP / (TP + FP)
Recall (Duyarlılık/Sensitivity)

Gerçekte pozitif olanlar arasında doğru tahmin edilenlerin oranı.

Recall = TP / (TP + FN)
F1-Score

Precision ve Recall'un harmonik ortalaması.

F1-Score = 2 × (Precision × Recall) / (Precision + Recall)
Specificity (Özgüllük)

Gerçekte negatif olanlar arasında doğru tahmin edilenlerin oranı.

Specificity = TN / (TN + FP)
Confusion Matrix Terimleri
  • TP (True Positive): Doğru pozitif tahminler
  • TN (True Negative): Doğru negatif tahminler
  • FP (False Positive): Yanlış pozitif tahminler
  • FN (False Negative): Yanlış negatif tahminler
